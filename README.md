---

### 🛡️ Почему за файлы не банят

У изменённого файла есть только **два исхода** — третьего «файл неверный → бан» просто не существует:

```
📁 Изменённый файл  →  игра при запуске сверяет
                       ├─ ✅ верный      → пропуск, играем
                       └─ ⬇️ не хватает  → ошибка, докачка
```

> 💡 Файлы могут отличаться по куче обычных причин: сбой загрузки, зависание ПК, битые секторы, старая версия. Поэтому «неверный файл» в принципе не является поводом для бана.

---

### 🧩 Разница между играми

- ⏰ **HoYoverse (Genshin, Star Rail, ZZZ) — два слоя.** Файлы не проверяются + есть предупредительный бан на 7 дней перед постоянным. Максимально мягко к игроку.
- ℹ️ **Hypergryph (Endfield) — не страшнее, просто чуть иначе.** Файлы проверяются шифрованным хешем и чаще. Предупредительного бана нет, но логика та же: не хватает файла → докачка, а не бан. Небольшое неудобство, не риск.
